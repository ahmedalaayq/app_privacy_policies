Needs a link Privacy Policy URL

Apple requires a live page, not a text file. Fastest free route: host it on GitHub Pages, since the team already has a GitHub org.

  1. Create a new repo, e.g. beturn-legal
  2. Upload privacy-en.html and privacy-ar.html
  3. Settings → Pages → Deploy from branch → main
  4. Paste the resulting URL into the Privacy Policy URL field
https://codeikoo.github.io/beturn-legal/privacy-en.html
https://codeikoo.github.io/beturn-legal/privacy-ar.html
